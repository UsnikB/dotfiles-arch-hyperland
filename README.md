# Arch Linux Hyprland Rice

This repository contains my personal dotfiles for a customized Arch Linux Hyprland environment.

## Prerequisites

*   A fresh installation of Arch Linux.
*   An active internet connection.
*   `git` installed (`sudo pacman -S git`).

## Installation

1.  **Clone the repository:**
    ```bash
    git clone <repository-url>
    cd <repository-name>
    ```

2.  **Backup existing dotfiles:**
    Before proceeding, it's recommended to back up your existing configuration files.

3.  **Run the installation script:**
    This script will copy the configurations to your `~/.config` directory.
    ```bash
    ./install.sh
    ```

## Managed Configurations

*   `hypr`
